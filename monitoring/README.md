# Monitoring

This directory is reserved for the NMI Grounded Continuation (GC) implementation and monitoring evaluation. The code has not yet been uploaded.

The module will cover post–target relation classification, salience, symbolic direct-support checks and the evaluation of agents' responses to the monitor. Associated entity and claim-type controls can be included with their evaluation scripts.

When adding the implementation, replace this notice with setup instructions, input formats, experiment commands and the exact scoring definitions. Distinguish the monitor's assessment from the agent's response condition, and document how the outputs correspond to the manuscript results.

Keep module-specific dependencies and configuration files here. The original Generative Montage release is available in [`../lying_with_truth/`](../lying_with_truth/README.md).
